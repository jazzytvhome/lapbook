✅ You're already live — no setup needed! This app syncs over a free public relay. You and your friend just need the same room code (use 🎲 New code → 🔗 Copy invite link). Edit from different computers and you'll see each other's changes in real time.
Heads up: the free relay is best-effort and not private — anyone who guesses your room code could view it. For a private, rock-solid setup, do the optional Google Firebase steps below (free, no card). Once you add a Firebase config, the app automatically uses it instead of the public relay.

Step 1 — Create a free Firebase project (~2 min)

  1. Open console.firebase.google.com, sign in with Google.
  2. Add project → any name → Continue (skip Analytics) → Create project.

Step 2 — Turn on the Realtime Database

  1. Left menu → Build → Realtime Database → Create Database.
  2. Any location → Start in test mode → Enable.

Step 3 — Get your config

  1. ⚙️ gear (top left) → Project settings.
  2. Your apps → web icon </> → register (any nickname).
  3. Copy what's inside the firebaseConfig = { ... } block.

Step 4 — Paste it into the app

  1. Open index.html in a text editor (right-click → Open with Notepad).
  2. Near the top find window.FIREBASE_CONFIG = { } and paste your keys inside.
  3. Make sure it has apiKey and databaseURL. Save, then reload this page → badge turns 🟢.

Step 5 — Play together

  1. 🎲 New code makes a room → 🔗 Copy invite link → send it to your friend.
  2. You both open the link → same room → edits sync live. Dots show who's online.
Already on Vercel? This page is deployed there as a static site — just paste your Firebase config into index.html, redeploy, and live sync runs for everyone.

Test-mode rules are open to anyone with the link — fine for two friends; don't store private info.
